# 服务器节点创建、导入与订阅限制

## 在总控选择服务器创建节点

1. 先在「服务器管理」登记并验证目标服务器。
2. 进入「节点管理 → 选择服务器创建节点」，选择服务器。
3. 按目标内核可用的模板填写节点参数、监听端口、SNI 或证书路径，创建节点。也可在服务器节点页创建中转。
4. 新建入站自动归属当前订阅，默认在创建后导入连接；后续可在「流量与有效期」配置订阅总额度与到期时间。

节点管理原有的普通新增按钮仍只编辑订阅中的客户端配置；真正创建远端入站请使用“选择服务器创建节点”。服务器安装任务进行中时不能执行节点操作。

## 导入现有面板中的节点

在「节点管理 → 从服务器导入节点」选择服务器，查看远端入站列表，点击对应行的「链接 / 导入」。可以勾选该入站中需要的连接。

- **仅导入连接信息**：将连接添加到当前订阅，不新增订阅所有权，也不自动启用服务器流量或到期撤销。
- **导入并绑定当前订阅**：适用于仅供当前订阅使用的专属入站。确认该入站专用后导入，再到「流量与有效期」启用强制限制。

服务器上的真实连接会在提交时重新读取，不信任浏览器提交的连接凭据。重复导入相同配置会复用已有节点，不不断生成重名副本。新增节点加入普通手动选择组，不插入受管主备组。

其他订阅已占用的入站不能重复认领。已启用强制限制的订阅不能通过此导入流程加入未绑定的连接；可选择专属入站进行绑定，或新建专属入站。

## 限额与有效期如何联动

绑定以整个入站为单位，当前不提供共用入站内按单个用户撤销的能力。因此，多用户入站可以选取连接导入，但不能整组绑定强制限制；需要先创建独立入站。

绑定后从远端当前计数开始累计，历史用量不会自动记入。需要继承历史用量时，可在流量页面录入已用上传与下载值。总控不会自动取消原面板自身设置的限额或有效期；原面板更严格的限制仍可能提前生效。

在「流量与有效期」设置总额度、到期时间并启用强制限制后：

- 同一订阅在不同服务器上的专属入站用量聚合计算。
- 到期或超额时，后台巡检撤销该订阅的专属入站，订阅下载也被阻止。
- 巡检存在时间间隔；离线服务器无法立即完成撤销，会保留错误并重试。
- 已下载的链接仍受远端入站撤销约束。续期不会自动复活已删除入站，需要重新创建节点。

“绑定”与“开启限制”是两个步骤，绑定成功本身不代表已经启用额度或到期撤销。页面会显示当前绑定状态并提示下一步。

## 已删除节点为什么还可能显示在绑定列表

这里管理的是“订阅与远端入站的绑定记录”，不等同于远端实时节点列表。远端删除后重建、复用同一入站 ID，或修改认证身份时，旧绑定不能再代表当前节点。

身份校验失败会将旧绑定标记为“身份已变化（停止管理）”，移入折叠的失效历史，停止对它继续计量或自动操作。旧版曾只写入身份变化错误、却保留 active 状态的记录，升级后从本地索引加载时会自动整理；不需要连接全部服务器。普通离线不会被当作身份变化。

每条有效绑定和历史绑定旁都提供“删除记录”，可直接手动移除不存在或不再需要管理的本地关联，不依赖自动识别结果。确认框会提示：若远端节点实际仍存在，删除绑定后总控不再通过该记录计量、暂停或撤销节点；服务器已有的限速或暂停状态保持原样，不会自动恢复。已计费用量、套餐、订阅链接及订阅里的节点配置均保留。若列表已变动或记录被替换，接口会要求刷新后重试，不按复用的 ID 盲删。

可展开“失效历史绑定”并点击“清理失效历史绑定”。此操作只删除当前订阅的本地历史关联，不连接服务器、不删除远端节点、不清空已计费用量，也不移除订阅 YAML 里的节点链接。订阅节点列表中的旧连接需要在“节点管理”另行核对。身份变化不是自动接管新节点的依据，需明确确认新的归属。

## 当前支持范围

已接入的 3x-ui、X-ui、X-Panel 可读取各自兼容接口返回的现有入站及分享链接；不支持导出的协议或缺少参数的入站不能直接导入。

独立 Xray、sing-box 当前仅展示总控创建的受管入站，不会自动接管手工写入原生配置的旧入站。未受管旧配置会保留。请不要把“已接入内核”理解为“原有所有入站已自动转换为总控节点”。

## 失败后的处理

- 远端节点已创建、订阅导入失败：从远端入站的“链接 / 导入”重试，不要重复创建。
- 现有入站已绑定、写入订阅失败：专属绑定保留，错误信息会说明；重试导入不会删除现有远端节点。
- 节点已被其他订阅绑定、已撤销或身份发生变化：先核对远端状态，必要时为当前订阅新建专属入站。

本地检查覆盖服务器选择界面、按连接导入、重复导入、专属认领、跨订阅保护、多用户入站拒绝绑定，以及导入节点的到期和总流量撤销。浏览器使用模拟服务器数据；线上面板连接与客户端访问需在部署后验证。
