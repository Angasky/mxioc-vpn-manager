# 共用入站与独立订阅用户

## 使用方式

1. 添加服务器并验证接入。
2. 在节点管理点击「选择服务器添加订阅节点」，选择服务器和已有入站。
3. 点击「复用入站并添加订阅用户」。总控自动生成独立 UUID / 密码，写入远端用户列表，并把此用户的连接加入当前订阅。同一订阅重复操作会复用已有用户。
4. 在「流量与有效期」设置套餐、额度、到期时间并启用服务器强制限制。
5. 下一份订阅选择同一个入站即可，无需另开端口、证书或 Reality 密钥。

首次没有入站时，选择「创建新共用入站」，按模板创建一次。普通本地节点编辑和链接导入不会自动获得服务器授权管理能力。

支持多用户模型的协议为 VLESS、VMess、Trojan，以及独立 sing-box 的 Hysteria2 / TUIC。VLESS、VMess 使用 UUID；Trojan、Hysteria2 使用独立密码；TUIC 使用 UUID 和密码。普通单密码 Shadowsocks 模板、外部 Mieru 链接等不能由此模式强制控制，不能只凭共享端口推断用户身份。

## 计费和撤销

- 绑定保存服务器、入站、用户 email 和认证身份指纹，不把其他用户的增删作为当前用户身份变化。
- 从远端读取该 email 的认证流量，不使用共用入站或端口的合计流量。计数缺失时报错并等待重试，不能当成零流量。
- 新用户从零开始累计；旧绑定迁移先按旧倍率结算，再切换计数基线，不重算已计费历史。修改倍率仍先结算旧用量。
- 同一订阅多个服务器的用户用量聚合。一次性额度耗尽或订阅到期，删除此用户授权，不删除入站、其他用户、中转路由；订阅下载被阻止。
- 月额度耗尽只禁用此用户，下一周期恢复。管理员手动停用的用户不会被擅自接管自动恢复。
- 每次远端操作都会重新核对入站与用户指纹。入站或凭据被替换时停止自动操作，避免误删复用身份。
- 默认每 30 秒巡检，服务器离线会重试。删用户禁止新的认证连接；已建立连接何时结束取决于远端内核和面板实现。不会用清空共用端口 TCP 连接的方式强断所有用户，也不承诺旧长连接在到期瞬间全部断开。

## 面板和独立内核条件

| 接入方式 | 用户操作与计量 |
| --- | --- |
| 3x-ui、兼容 X-ui、xeefei/X-Panel | 使用 `addClient`、`updateClient`、`delClient` 单用户接口和 `clientStats`。旧版缺少接口时操作失败并提示核对，不会悄悄改成删除整个入站。 |
| 独立 Xray | 仅管理总控已有的受管入站；配置 loopback StatsService 和用户统计策略，以远端 Xray CLI 查询非重置计数。原生校验后应用，失败尝试恢复。已有非总控统计 API 不会覆盖。 |
| 独立 sing-box | 要求带 `with_v2ray_api` 的构建，同时远端有 `/usr/local/bin/xray` 作为 StatsService 查询工具。创建前检查构建支持；当前测试的官方 sing-box 1.14.4 不含此编译标签，会明确拒绝，不支持将端口总流量冒充用户用量。 |

原生内核配置变更仍采用校验后重启服务的现有适配机制，会短暂影响该服务其他连接并重置内存统计；两个采样之间重启可能损失未采集用量。面板路径使用用户接口，其热更新/重启行为由面板决定。此版本未提供无损热更新或硬实时记账保证。

共用模式暂不支持按用户带宽限制。套餐或节点限速非零时拒绝应用，禁止把旧版端口规则施加给所有共用用户。清除旧限速后再迁移；流量额度、倍率和到期不受此限制。

## 旧订阅迁移

旧版专属入站不再作为新界面的默认创建方式，兼容 API 和存量绑定保留，防止升级直接丢失所有权或历史账单。旧绑定未迁移前继续按原规则处理。

切换到原订阅，在对应入站点击「添加订阅用户」→「添加 / 迁移当前订阅用户」。总控核验唯一用户、原归属及身份，结算旧用量后保留原 UUID、订阅链接、套餐和历史用量，转成用户级绑定。旧入站暂停、仍有端口限速、缺少唯一用户计数或属于其他订阅时拒绝迁移，需先处理提示的问题。不会静默批量合并旧入站。

## 失败恢复

远端操作前保存待核对身份记录；超时后重试同一入站会核对已存在用户，不重复分配 UUID。如果用户确实未写入远端，核对后删除待核对的本地记录再重试。删除本地绑定不删除远端用户，也不会清空历史计费。

用户已绑定但导入订阅失败时保留绑定，在同一入站重试添加即可。首次新建入站后若后续计量初始化失败，会提示已创建的入站 ID；保留基础入站供修正后重试，不重复创建，也不盲删可能已有其他用户的入站。

## 验证范围

单元/集成回归覆盖双订阅共用端口、独立用量与倍率、重复采集、月暂停恢复、到期及总额撤销、身份替换、离线重试、创建超时恢复、旧绑定迁移、磁盘写入失败、真实 HTTP 鉴权及订阅阻断。Chromium 验证三个主题的桌面和手机表单、切换订阅保护及失败重试。

可选真实内核测试：

```sh
MXIOC_XRAY_BIN=/path/to/xray MXIOC_SING_BOX_BIN=/path/to/sing-box \
  python -X utf8 -m unittest discover -s tests -p 'test_shared_users_native.py' -v
```

真实测试仅使用临时配置和 loopback 端口，验证 VLESS 两个 UUID 共用端口、独立认证流量、停用一个 UUID 后另一个仍可建立新连接；检查 sing-box 编译能力。未操作生产服务器，也不代表所有版本面板或 WAN 连接已实测。
