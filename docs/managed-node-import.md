# 服务器节点与订阅同步

- 服务器节点列表可单选、多选及全选当前页，再导入一份或多份订阅。
- 每份订阅仍分配独立用户凭据；不会复制其他订阅的 UUID / HY2 密码。
- 选择订阅时，已导入全部所选节点的订阅隐藏；部分导入的只补缺少项。创建待核对记录仍可重试，成功项不重复提交。
- 删除本地订阅节点后可再次导入，不会仅凭历史绑定错误隐藏目标。

刷新服务器入站列表后，以及后台巡检确认远端入站缺失后，总控清理其拥有的本地订阅节点、失效链式节点及策略组 / 规则引用。空策略组回退 DIRECT，保留绑定历史和已计费用量。关闭流量强制限制也会核对节点是否存在。

服务器离线、登录失败、读取异常或列表格式异常不作为删除依据。清理按保存的节点身份指纹核对；旧独立用户记录可通过 email 与凭据摘要确认。仅同名、同端口或复用入站 ID 不授权删除另一节点。未建立归属的手工粘贴连接、缺少可核验身份的旧整入站记录不会被猜测删除。

写入失败保留历史和待重试状态；镜像部分写入后，下次会修复镜像，不把主文件已清理误当成全部完成。

接口 `POST /admin/api/servers/users/targets` 接收 `serverId` 和 1–50 个 `inboundIds`，返回每份订阅的 `importedInboundIds`。该接口只读取本地归属和配置，不读取 SSH、不返回订阅 token 或节点密码。真正导入仍经已有独立用户接口逐个核验，并在配置保存后才确认完成。
